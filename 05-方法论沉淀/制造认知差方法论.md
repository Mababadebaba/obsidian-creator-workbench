# 制造认知差方法论

> 💡 想获客就不要上来解决问题，要先「制造问题」——不是制造焦虑，是制造认知差：让他知道以前不知道的，怕以前不怕的。
> 关联：[[短视频开头方法论]]（第 6 式·认知差式）| [[账号方向优先方法论]] | [[选题方法论]] | 增长策略（私有 · 未包含）

---

## 核心逻辑

你上来就讲方法、给方案，观众觉得学到了、自己能搞定，就不找你了。

但你先让他看到一个**他没意识到的问题**——"你现在的做法可能正在毁掉 X""你之前的钱大概率白花了""你以为对的其实是错的"——他慌了，发现问题比想象中严重，自己根本搞不定。这时候你再说"我有办法"。

> 他不是因为你有答案才找你，是因为你让他看到了他之前没意识到的问题。
> 问题越大，付费意愿越强。

```
解决问题型内容：给方法 → 观众学会 → 关系结束
制造认知差型内容：揭示盲区 → 观众意识到搞不定 → 你成为出口 → 关系开始
```

## 三步结构

1. **揭示盲区**：指出对方正在做、但不知道有问题的事（必须具体到行为，不是泛泛"你不行"）
2. **具体化代价**：这个盲区正在让他损失什么——时间/钱/机会/账号权重，代价越可量化越有力
3. **给出口**：我有办法 / 我踩过这个坑走出来了。**出口必须真给**，视频内至少给到第一步，完整方案留在评论区互动或下期

## 在本账号的应用场景（AI / Vibecoding / Builder）

### 场景 A：开头钩子（→ [[短视频开头方法论]] 第 6 式）

- 「你现在用 Claude 的方式，可能一直在让它给你打七折」
- 「你收藏的那几十个 AI 教程，正在拖慢你上手的速度」（Codex 场景分析法稿的 ② 痛点段就是这个结构——已有实践）
- 「大部分人做 AI 产品的第一步，就注定了会被下个版本的模型清空」（15 度夹角选题的天然认知差开头）

### 场景 B：选题角度（诊断型选题）

同一主题的两种做法：
- 教程型：「Codex 入门教程」——观众学完就走
- 诊断型：「为什么你的 Codex 一直用不起来」——观众先意识到自己方法错了

选题库里每类主题都可以问一句：**这个主题有没有"大家都在犯但不自知"的错误版本？** 有，优先做诊断型。

### 场景 C：CTA / 获客（→ 增长策略（私有 · 未包含） 意向收集阶段）

诊断型 CTA 比赠品型 CTA 筛出的意向更准：
- 赠品型：「评论区扣 X 领资料」→ 引来薅羊毛的（且撞风控）
- 诊断型：「评论区说你的场景/问题，我帮你看看卡在哪」→ 引来真的意识到自己有问题的人 = 谱系左端付费人群

## ⛔ 红线（认知差 ≠ 恐吓营销）

1. **必须真实可论证**：揭示的问题必须真的存在、你能讲清楚为什么。虚构的威胁被一条评论拆穿，人设即死
2. **必须给出口**：只吓不给方法 = 制造焦虑 = 你「不希望变成」清单里的卖课博主话术。三步结构的第三步不能省
3. **语态守 B 位**：用"我踩过这个坑"的过来人语态，不用"你完了"的审判语态——揭示盲区的最好方式是自曝自己曾在盲区里
4. **风控**：夸大灾难性后果的词（"毁掉""白花了""判死刑"）口播可用但**字幕慎写**，参考 流量诊断记录（私有 · 未包含） 违禁词自查；不得配合导流话术使用
