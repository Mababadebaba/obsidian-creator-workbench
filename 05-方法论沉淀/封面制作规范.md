# 封面视觉品牌规范 v4（美漫墨线风 · 定稿）

> 💡 品牌基因已冻结：配色（黑/荧光绿/白）× 笔触（美漫墨线，试镜 C 胜出）。
> 封面 = 五个组件拼装：底图（一次性）+ 艺术字标题 + 真人贴纸 + 主题视觉 + 爆炸贴。
> 一致性三层锁：固定风格块（逐字复用）+ 风格样张参考图 + 素材库复用。生图工具：GPT。
> 关联：[[剪辑制作技巧]] | [[内容生产SOP]] | [[02-选题排期]]

---

## 一、品牌基因（已冻结）

| 层 | 定稿 |
|---|---|
| 配色 | 黑底 + 荧光绿 `#00E676` + 白，仅此三色（网点/墨线可用纯黑白） |
| 笔触 | **美漫墨线风**：粗墨线描边、半调网点阴影、爆炸框/速度线、贴纸质感 |
| 品牌记号 | 白边贴纸真人 + 漫画元素体系本身即记号；吉祥物暂缓（有需要再按本风格配套） |

### 📌 定稿风格块（所有生图逐字带上）

```
bold comic-book ink style, heavy black ink outlines, halftone dot shading,
neon green (#00E676) and white two-tone accents on pure black, small action
lines, manga cover energy, flat graphic, sticker quality
```

## 二、封面五组件

| # | 组件 | 来源 | 频率 |
|---|---|---|---|
| 1 | 底图：纯黑 + 极淡半调网点纹理 | GPT 生成一次 | 一次性，全年复用 |
| 2 | 艺术字标题（≤8 字） | 风格块 + 样张参考图生成，4 选 1 | 每期（高频词入库复用） |
| 3 | 真人贴纸（**白色粗描边包裹**） | 当期视频截图 → 见下方人物管线 | 每期 |
| 4 | 主题视觉：本期主体的漫画风插画（手机+机器人 / 一摞书打叉 / 地球爆炸…）**或**案例截图装进白边漫画分格框 | 风格块生成 / 截图+剪映加框 | 每期，二选一 |
| 5 | 爆炸贴/对话气泡：本期硬数字（"27个案例!""已开源!"） | 常用的生成后入库复用 | 每期 1-2 个 |

排版松网格：标题占 40-60% 可倾斜叠压，人物下半区，主题视觉避让标题。

### 📐 尺寸规定（2026-07-25 O9 期用户裁定，覆盖旧 9:16 口径）

**每期交付两份**：竖版 **3:4（1080×1440）** + 横版 **4:3（1440×1080）**，抖音标准。
横竖版各自重排构图（横版人物可移一侧、标题横铺），**禁止**单一版式裁切/加黑边凑另一版式。
交付自检必须 ffprobe/identify 实测像素尺寸。

## 三、人物管线（截图生成制，无需拍照）

> 每期封面人物**直接取自当期视频截图**——附带解决服装一致性：封面人物和视频里穿的自动是同一件，观感真实且期期成立，比单独拍"制服照"更稳。

1. **截图**：从当期成片里截一帧表情/姿态可用的半身帧（1080P 以上，脸部清晰）
2. **生成动作（可选）**：截图喂给 GPT——
   ```
   Same person as the reference photo, keep the face and outfit exactly identical,
   change the pose to {摊手 / 指向左上 / 抱臂 / 惊讶捂头 / 举手机}, half-body,
   photo-realistic, plain solid background for easy cutout, studio lighting
   ```
   出 2-4 张挑脸最像的一张
3. **⚠️ 人脸还原度红线**：生成结果脸不够像本人 → **放弃生成，直接用原始截图**。封面人脸是账号识别核心，宁可动作平淡不可脸崩
4. **抠像 + 白边**：剪映智能抠像 → 描边：**白色、粗（约 8-12px 等效）、实边**——白边在剪映做不在生图做（宽度可控、每期一致）
5. 好用的动作生成结果同步存 `02-素材库/封面人物库/`，动作可跨期复用

## 四、一次性准备清单

**必做（一步到位流程只依赖这一件）：**

- [ ] **风格样张**：用定稿风格块让 GPT 出一张合集图（含「AI」「开源」「实测」等高频词艺术字 + 爆炸框 + 对话气泡 + 箭头速度线，黑底荧光绿）→ 存 `02-素材库/封面品牌/风格样张.png`，之后每期生成都挂它当参考图

**Plan B 备件（降级分层时才需要，可等真用到再做）：**

- [ ] 底图：`pure black background with extremely subtle white halftone dot texture in corners, comic book paper feel, minimal, no other elements, 3:4`（横版另出 4:3 一张）→ `02-素材库/封面品牌/底图.png`
- [ ] 爆炸贴首批：「已开源!」「实测!」「爆了!」透明底贴纸 → `02-素材库/封面品牌/爆炸贴库/`
- [ ] 剪映封面模板草稿（各组件占位）

### Plan B（降级路线，自动重生成 2 轮仍脸崩/错字时用）

改分层：艺术字/主题视觉/爆炸贴分开生成（各自挂样张 + 风格块），人物用原始截图剪映抠像 + 白粗边，剪映模板拼装。分层素材入库复用（备件清单见第四节）。

## ⛔ 红线

- 三色系冻结；风格块逐字复用；生图必挂风格样张
- 人脸还原度不足 → 用原截图，不将就
- 中文艺术字逐字校对笔画
- 标题 ≤8 字；封面不放账号名 logo
- 白边描边在剪映做（宽度统一），不靠生图
- 实验期内（前 12-15 篇）基因冻结

## 疲劳防线（色不变，构图变）

> 原则：**色和笔触是声纹，构图和表情是情绪——声纹不变，情绪要变。** 推荐流里统一配色=辨识度（观众一次只看到你一张）；九宫格里统一配色=专业感（促关注）。真正的疲劳来自构图单调，不来自颜色。

- 每期必须变化的：人物表情/姿势、标题大小与倾斜角度、主题视觉主体、爆炸框位置
- **反色特例（泄压阀）**：荧光绿底+黑字的反转版，同笔触同三色系，仅限里程碑事件（破万粉/爆款破百万/重大发布），**十期最多一次**——有计划的破例是"这期有大事"，随机换色才是乱
- 数据裁决：发满 15-20 篇后若点击率持续阴跌，复盘时再评估调基因；在此之前不为猜测破坏一致性
