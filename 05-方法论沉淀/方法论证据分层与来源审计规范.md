# 方法论证据分层与来源审计规范

> 这是一份**项目治理规范**，不是传播规律。它规定本系统如何保存、引用、推导和验证方法，防止把作者原话、AI 总结、跨样本观察与本账号结论混成同一种“方法论”。

## 一、六种来源层级

| 层级 | 名称 | 定义 | 允许使用的措辞 |
|---|---|---|---|
| L0 | 原始材料 | 视频、逐字稿、文章、数据截图、后台数据 | “原材料显示／原话是” |
| L1 | 来源复述 | 不改变原意的压缩、重排和解释 | “作者提出／原视频认为” |
| L2 | 系统推导 | Agent 或本系统为了执行而新增的概念、表格、公式、检查项 | “本系统推导／候选工具” |
| L3 | 跨样本观察 | 在明确样本范围内重复出现的模式 | “在 N 条样本中观察到” |
| L4 | 本账号验证 | 本账号按预先口径发布、回收并比较的数据结论 | “本账号 N 条数据暂时支持” |
| O | 运营规范 | 用户为了保持一致性主动选择的流程和约束 | “本项目规定／当前执行规则” |

`O` 与 L0—L4 正交。一个流程可以因为便于协作而被设为硬门，但不能因此被称为已经验证的传播规律。

## 二、必须遵守的来源纪律

1. **原话与改名分开**：只要替作者更换了核心术语，就进入 L2；不能继续写成作者的方法。
2. **推导过程可见**：L2 必须说明从哪条 L0/L1 出发、增加了什么、为什么增加。
3. **样本范围可见**：L3 必须写样本数、筛选规则、对照组和不能解释的反例。
4. **互动数据不等于因果验证**：高赞只能说明作品表现，不证明其中某一结构导致高赞。
5. **单一来源不升级为规律**：一条视频或一位作者的经验，只能作为来源观点或候选方法。
6. **适用范围不能扩张**：原方法讲开头，就不能未经说明扩成完整正文理论；讲获客，就不能直接当作传播规律。
7. **检查表注明作者**：自行设计的评分维度、阈值、账本和 A/B/C 分级必须明确写“本系统设计”。
8. **复述验证和理论验证分开**：使用 L2 量表分析样本，只能验证该量表是否有解释力，不能声称验证了 L1 原理论。
9. **阈值要有出处**：百分比、秒数、发布时间、预算和样本门槛必须标明是来源建议、系统默认值还是账号数据结果。
10. **反例必须保留**：出现结构过关但数据差、结构不完整但数据好时，不能为了维护方法而删除。

## 三、方法文件的最小证据头

新增或大改方法文件时，正文开头至少写：

```yaml
source_type: 原视频|用户心得|跨样本归纳|本系统治理规范
source_count: 1
evidence_level: L1|L2|L3|L4|O
account_validation_count: 0
```

正文再固定补四块：

1. **来源原话／原始事实**：可回到具体文件或时间戳。
2. **忠实复述**：只解释原作者说了什么。
3. **系统推导**：新增术语、公式和检查表全部放这里。
4. **验证状态与反例**：写清什么已观察、什么还不知道。

一份文件可以同时包含多层，但每个章节必须标层，不能只在 frontmatter 写一个模糊的 `source_type`。

## 四、状态字段的解释

- `已收录`：文件存在并可检索，**不代表已验证**。
- `待验证`：已有候选方法，但缺少本账号对照数据。
- `持续更新`：规则或证据仍在演进。
- `已验证`：只有达到事先约定的账号数据门槛后才能使用，并同时写明样本数与结果边界。

标签、标题和正文不得出现“已验证”，同时数据区为空或只有单一样本。

## 五、从来源到规则的升级路径

```text
L0 原材料
→ L1 忠实复述
→ L2 明示的系统假设
→ L3 带反例的跨样本观察
→ 预先定义本账号测试
→ L4 本账号暂时验证
→ 持续复盘，必要时降级
```

任何一层都可以直接作为灵感或诊断工具使用；只有 L4 才能写成本账号的经验规律。O 层可以直接执行，但必须承认它是项目选择，不是流量保证。

## 六、交付前来源自检

- [ ] 我有没有把作者没说过的术语写成作者原话？
- [ ] 我有没有把一条高赞视频当成结构因果证据？
- [ ] 我有没有把开头方法扩张到整条视频？
- [ ] 我新增的公式、阈值和评分表是否标为 L2 或 O？
- [ ] “必须／铁律／唯一／已验证”后面是否有对应证据等级？
- [ ] 这条结论有没有反例，是否已经写出来？
- [ ] 当前用途是启发、诊断、内部规范，还是预测？有没有说清？

自动检查：修改方法库后运行 `python3 tools/check_method_provenance.py`。它只检查证据头与“已验证”状态是否自洽，不替代人工判断章节归类是否正确。
