# PREP 与 SCQA 短视频表达结构方法论

> 💡 PREP 用“观点—理由—案例—重申观点”把一个观点讲透；SCQA 用“情境—冲突—问题—答案”把一个问题讲出推进感。两者解决的不是选题，而是表达清晰度与信息承接。

## [L1/L2] 核心框架

短视频文案常见的两个结构问题是：有结论但没有论证，或者有经历但没有推进。PREP 适合观点表达、推荐和讲道理；SCQA 适合吐槽、案例、问题诊断和解决方案。它们都能降低观众理解成本，但不能单独保证爆款，仍需配合选题、开头钩子、证据与节奏。

| 模型 | 展开顺序 | 适合内容 | 核心作用 |
|---|---|---|---|
| PREP | Point → Reason → Example → Point | 观点、推荐、知识解释 | 让观点有依据、有画面、有回扣 |
| SCQA | Situation → Complication → Question → Answer | 故事、痛点、诊断、方案 | 用冲突制造推进，并自然导向答案 |

## 一、[L1] PREP：作者介绍的观点结构

### 1. Point：先给观点

- 开宗明义，不让观众先猜结论。
- 观点要具体到可以被支持或反驳。

### 2. Reason：解释理由

- 回答“为什么”。
- 理由负责建立逻辑，不要只是换一种说法重复观点。

### 3. Example：给出案例

- 用亲身经历、具体场景、数据或对比，让抽象理由变得可感知。
- 案例最好与观众的日常经验相连。

### 4. Point：重申观点

- 不是机械复读，而是把前面的理由和案例收束成一句行动结论。
- 让观众在段落结束时记住真正要带走的内容。

### 原视频示例：推荐一部电视剧

1. **观点**：这部剧你一定要看。
2. **理由**：剧情紧凑、有反转，而且演员演技在线。
3. **案例**：我昨天熬夜看到三点，根本停不下来。
4. **重申观点**：所以这部剧你一定要去看。

### [L2] 本系统改造成短视频段落

> 观点先行 → 给出两条理由 → 插入一个最小故事单元 → 用一句更有力度的观点回扣。

这与 [[爆款口播内容设计方法论]] 的“观点必须配最小故事单元”一致：PREP 提供局部论证骨架，故事单元提供人物、冲突、选择和结果。

## 二、[L1] SCQA：作者介绍的问题结构

### 1. Situation：交代情境

- 给观众一个熟悉、稳定的背景。
- 情境只需够用，不要在铺垫阶段堆太多细节。

### 2. Complication：加入冲突

- 说明现状为什么不能继续。
- 冲突可以是代价、变化、障碍或反常现象。

### 3. Question：提出关键问题

- 把冲突收束成一个需要回答的问题。
- 问题应能自然打开后面的解决方案，而不是为了互动硬加一句问话。

### 4. Answer：给出答案

- 答案要对应前面的问题，最好是一条明确行动或一个可执行框架。
- 如果答案较长，可以继续拆成新的 PREP 段落。

### 原视频示例：吐槽上班疲惫

1. **情境**：最近上班真的很累。
2. **冲突**：每天加班到很晚，回家只想躺在床上。
3. **问题**：是不是没有规划好工作和休息时间？
4. **答案**：以后每天下班先抽半个小时运动。

相比“上班好累，我不想上班”，SCQA 让表达有背景、有原因、有下一步，也更适合被观众持续听下去。

## 三、[L2] 本系统的组合方式

### 组合方式 1：SCQA 搭整条，PREP 写段落

- 用 SCQA 建立整条视频的情境、冲突、核心问题和总答案。
- 在答案部分，用若干 PREP 段落分别讲清每个方法。

### 组合方式 2：PREP 搭整条，SCQA 做案例

- 开头先给观点。
- 理由之后插入一个 SCQA 小故事，让案例内部也有推进。
- 结尾回扣观点并给行动。

### 组合方式 3：与时钟理论叠加

- PREP、SCQA 解决逻辑顺序，[[短视频文案节奏方法论（时钟理论）]] 解决信息点分布。
- 结构正确不等于节奏有效；仍需检查每个刻度区是否有新信息，3/6/9/12 节点是否发生阶段推进。

## 四、[O] 使用边界

- **不能替代选题**：方向外、需求弱的内容，结构再清楚也很难获得传播。
- **不能替代开头**：PREP 的第一个观点仍要按 [[短视频开头方法论]] 做结果前置、认知差或痛点表达。
- **不能只填字母**：每一格都必须增加新信息，不能把同一句话改写四遍。
- **案例必须真实具体**：Example 不是泛泛举例，最好包含人物、场景、行为与结果。
- **答案必须兑现问题**：SCQA 最忌前面制造大问题，最后只给空泛建议。

## 五、[L2] 本系统写作模板

### PREP 模板

> 我先说结论：___。原因有两个：第一，___；第二，___。我自己/某个具体案例里，___。所以真正该做的不是___，而是___。

### SCQA 模板

> 过去/通常情况下，___。但现在出现了___，导致___。问题是：___？我的答案是___，具体分为三步：___。

### SCQA + PREP 组合模板

> **情境**：___。**冲突**：___。**问题**：___？**答案**：___。
>
> 第一，观点___；因为___；比如___；所以___。
>
> 第二，观点___；因为___；比如___；所以___。

## 来源原话与系统总结句

- [L0] 「说话其实就是一门技巧，拍短视频也是一样的。」
- [L2] 「PREP 的精髓，是先给观点，再用理由和案例让观点站得住，最后把观点送回观众脑子里。」
- [L2] 「SCQA 不是把话说复杂，而是让观众知道问题从哪里来、为什么重要、接下来怎么办。」

## [L0] 完整文字稿

> 说明：云端 ASR 因临时音频隧道下载失败，以下根据视频内烧录字幕逐秒 OCR，并结合连续画面人工校订。个别语气词可能与原声略有差异，方法内容完整。

**开场：为什么需要脚本结构**

我不敢说你用完这个结构之后，保证你百分之百出爆款，但是你的完播率至少能够翻一倍。我的账号里面很多的爆款，都是按照这个节奏结构做的。而且我发现很多的商业大佬，以及很多知识付费的头部博主，他们一直都在用这个脚本结构。

**第一个框架：PREP**

第一个是 PREP 模型。P 是 Point，观点；R 是 Reason，原因；E 是 Example，案例；最后一个 P 还是 Point，观点。

先陈述你的观点，再讲你的理由，再讲一个跟你有关的案例，最后再重复你的观点。

给大家举个例子。你平时跟朋友聊天，推荐一部电视剧，可能你只会说：“这个电视剧特别好看，你赶紧去看。”

如果用 PREP 模型，你可以说：“这部剧你一定要看。不光剧情特别紧凑、有反转，而且演员的演技也特别在线。我昨天熬夜看到了三点钟，根本停不下来。这部剧你一定要去看。”

第一句是开宗明义，接着给出理由，再用自己的经历做具体解释，最后强调观点。

以后无论是跟朋友聊天、推荐什么东西，还是拍短视频、讲道理，都可以用得到。这就是 PREP 的精髓。

**第二个框架：SCQA**

第二个表达框架是 SCQA。S 是 Situation，情境；C 是 Complication，冲突；Q 是 Question，问题；A 是 Answer，答案。

我所有的视频文案里面，用到的都是这个框架。其实放到生活当中，如果你跟朋友吐槽，也很好沟通。

再举个例子：“最近上班真的很累，每天都要加班到很晚，回到家只想躺在床上。可能是没有规划好工作和休息时间。以后我每天下班，先抽半个小时出来运动。”

这么说，是不是比只说“上班好累，我不想上班”要好很多？

**结尾：把日常表达习惯迁移到短视频**

说话其实就是一门技巧，我们拍短视频也是一样的。大家可以把我刚才在日常生活中举例的说话表达习惯，用在短视频的表达里面。你就会发现，原来拍视频也有逻辑表达框架。

如果大家对表达习惯和表达逻辑感兴趣，可以在评论区告诉我，我可以继续给大家分享。
