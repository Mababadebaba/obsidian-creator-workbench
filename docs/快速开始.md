# 快速开始

## 1. 跑起来看效果

```bash
cd dashboard
python3 build.py       # 读上一级目录（示例 vault）→ 生成 9 个页面
python3 serve.py       # 本地起静态服务
```

打开 `http://127.0.0.1:8000`。仓库自带的是虚构示例内容，先看形态再换成自己的。

要求：Python 3.9+，无第三方依赖。

## 2. 指向你自己的 vault

不想动这个仓库的话，直接把 vault 路径传进去：

```bash
cd dashboard
python3 build.py --vault ~/path/to/your-vault --out ~/path/to/output
```

`build.py` 对文件路径和 Markdown 结构有明确预期，缺文件不会崩溃，只会在页面上少一块并打 warning。
完整要求见 [数据契约.md](数据契约.md)。

## 3. 把这个仓库当自己的 vault 用

1. 用 Obsidian 打开仓库根目录
2. 安装 Dataview 和 Templater 插件
3. 删掉 `01-` 到 `08-` 里的示例文件、`predictions/`、`scripts/`、`videos/`、`trends-history/`
4. **保留** `05-方法论沉淀/` 和 `templates/`——那些是方法，不是数据
5. 打开 `.gitignore`，把底部那几行私人内容目录的注释取消掉
6. 把 `CLAUDE.md` 顶部的平台、赛道、定位改成你自己的

## 4. 接上 Claude Code / Codex

仓库自带 `.claude/settings.json`，装了两个 hook：

- `session-start.sh`：每次会话开始注入当前状态（待复盘、候选池、发布节奏）
- `prediction-immutability.sh`：拦截对 `predictions/` 里已完成预测段的修改

Codex 侧读 `AGENTS.md`，它会把你导向 `CLAUDE.md`。

## 5. 常驻本地看板（可选）

```bash
bash 06-业务运营/cron/install-public-workbench-launchagents.sh
```

macOS launchd 常驻，定时重建 + 本地静态服务。**默认只监听本机**——
如果你要往公网放，先自己加访问控制：工作台页面内嵌了 vault 的全量数据。
